¿Como comenzamos?

Primero diseñamos el funcionamiento de la casa y decidimos qué componentes necesitamos para implementarlo y hacerlo realidad.

Después realizamos pruebas de la casa individuales antes de contruir todo el sistema, para asegurarnos de que cada componente funcione correctamente y cumpla con su función.

Pasos realizados

  1. Diseñar la maqueta

    2. Construir la maqueta de la casa y definir dónde estará cada habitación

  2. Probar la ESP32

    3. Comprobar que la ESP32 funcione y se programe correctamente

  3. Conectar los LEDs

    4. Programar el encendido y el apagado de las luces

  4. Conectar el servomotor

    5. Programar diferentes posiciones para representar:

    1. 🔓Puerta abierta
    2. 🔒Puerta cerrada
  5. Conectar el LDR

    6. Leer la cantidad de luz existente en el entorno

  6. Crear la página web

    7. Diseñar el dashboard de VIERNES utilizando:

    • HTML
    • CSS
    • JavaScript

Pruebas y cambios

¿Qué probamos?

Probamos cada componente por separado y posteriormente intentamos integrarlos.
Por ejemplo:

  1. Encender y apagar LEDs
  2. Mover el servomotor
  3. Leer el LDR
  4. Leer humedad
  5. Conectar la ESP32 al Wi-Fi
  6. Probar los botones de la página web
